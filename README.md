## The Funniest Sick-Day Excuse

A single one-line sick-day excuse, under 200 characters, that a boss might half
believe and a coworker would laugh at. `main.ts` writes it to `/output/entry.txt`.

The entry:

> My smartwatch just declared me clinically dead and I don't want to argue with the data

Why this line: wearables really do misread vitals, so a boss can half believe it;
it turns on a fresh idea instead of a worn fever, dog or dead-grandmother excuse;
the punch lands at the end; and it reads like a real person typing a message,
with no wasted words.

## Run

```sh
node main.ts
cat /output/entry.txt
```
